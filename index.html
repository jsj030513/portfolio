01. Closer — Safe Dugout 웹·네트워크 보안 점검/개선

약 1개월 반 · PM / 웹 보안 점검·네트워크 구성 · K-Digital Training 교육 프로젝트

SECURITY / NETWORK

목표: 국비지원 K-Digital Training ‘웹서버개발 및 웹보안 솔루션 구축 융합과정’에서 기존 Safe Dugout 서비스의 애플리케이션과 인프라 환경을 함께 점검했습니다.

웹 보안: Burp Suite로 HTTP 요청을 가로채 포인트 파라미터 값을 100에서 1000으로 변경하는 실습을 진행했습니다. 입력값을 신뢰할 때 발생할 수 있는 위험과 서버 측 유효성·권한 검증의 필요성을 학습했습니다.

네트워크 구성: Closer 프로젝트의 일환으로 Packet Tracer를 활용해 본사·지사 네트워크를 구성하고, VLAN, ACL, 이중화, 라우팅을 적용해 네트워크 영역을 분리하고 접근통제를 설정했습니다.

장애 분석: 본사·지사 통신 장애에서 게이트웨이, 라우팅 테이블과 ACL 규칙을 확인했습니다. 차단 규칙으로 필요한 통신이 막힌 경우 허용 정책을 검토·수정해 통신을 복구하는 실습을 진행했습니다.

Gateway → Routing Table → ACL → Reverse Routing

역할: PM으로 팀원별 진행 상황을 취합하고 작업 범위와 일정을 조율했습니다.

배운 점: 웹 요청 흐름과 네트워크 구조를 함께 확인하며 보안 문제를 분석하는 접근법을 익혔습니다.
