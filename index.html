01. HQ–Branch Network Lab

네트워크 구축 및 장애분석 실습

NETWORK

목표: 본사와 지사 환경을 구성하고 네트워크 분리, 라우팅, 이중화, 접근제어 및 서버 통신을 실습했습니다.

구성: VLAN, Trunking, EIGRP, HSRP/VRRP, ACL, NAT/PAT, DHCP, DMZ, Routing

문제 해결: HQ Server와 Branch Backup 간 통신 장애 상황에서 설정을 반복 변경하지 않고 패킷 이동 경로를 순서대로 확인해 문제 구간을 좁혔습니다.

Source IP → Gateway → Router Interface → Routing Table → ACL → Destination → Reverse Routing

배운 점: 장애 대응에서 중요한 것은 장비 설정을 먼저 바꾸는 것이 아니라 정상 구간과 비정상 구간을 구분해 원인을 좁히는 것임을 익혔습니다.

02. Closer — Safe Dugout 보안 점검/개선

약 1개월 반 · PM · K-Digital Training

SECURITY

목표: 기존 Safe Dugout 서비스의 애플리케이션과 인프라 환경을 함께 점검했습니다.

웹 보안: Burp Suite로 HTTP Request를 확인하고 Parameter 값을 변경해 서버 처리 결과를 검증했습니다. SQL Injection, XSS, CSRF 등 웹 취약점 실습 경험을 활용했습니다.

배운 점: 웹 취약점만 따로 보는 것이 아니라 요청 흐름, 서버 처리, 네트워크 구조를 함께 확인해야 문제를 정확하게 판단할 수 있음을 배웠습니다.
