## Main Projects

### Closer — Safe Dugout 웹·네트워크 보안 점검/개선

국비지원 K-Digital Training 교육과정에서 진행한 팀 프로젝트입니다.
PM으로 진행 상황과 일정을 조율하고, Burp Suite 기반 웹 요청 분석과 Packet Tracer 기반 네트워크 구성·장애 분석을 수행했습니다.
본사·지사 네트워크 실습(HQ–Branch)은 Closer 프로젝트에 포함된 작업입니다.

### 함께걸음 — 배리어프리 정보·돌봄회원 매칭 웹 서비스

K-Digital Training 팀 프로젝트에서 부팀장으로 참여했습니다.
로그인·회원가입·돌봄회원 마이페이지 개발을 담당하고, 일정이 지연된 팀원의 개발 작업을 지원했습니다.

### Project Eden — AI 도구를 활용한 기능 기획·테스트

캐릭터와 월드 상호작용을 중심으로 한 개인 웹 게임 프로젝트입니다.
코드 작성과 구현에는 Codex를 주로 활용했으며, 본인은 기능 기획과 테스트를 담당했습니다.
프로젝트에 사용된 Spring Boot, JWT, Docker Compose, React/Vite 등의 기술과 본인의 기여 범위를 구분하여 설명합니다.

### ARB//KOREA

거래소 가격 비교·자동화 시스템 개인 프로젝트입니다.
세부 기능과 운영 안전장치는 포트폴리오 사이트에 정리했습니다.
